# 写真を入れる場所

公開用の写真は、以下の名前で入っています。

- `slide-01.webp`
- `slide-02.webp`
- `slide-03.webp`
- `slide-04.webp`
- `slide-05.webp`
- `slide-06.webp`
- `slide-07.webp`
- `slide-08.webp`

写真の枚数やファイル名は、`script.js` の `photos` で変更できます。
JPEG のほか、PNG や WebP も使用できます。その場合は `file` の拡張子も合わせてください。

スマートフォンの写真は、1枚あたり 1〜2MB 程度まで圧縮すると表示が速くなります。
